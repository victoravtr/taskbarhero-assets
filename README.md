# taskbarhero-assets

Game art mirror for the TaskBarHero fan tool. Auto-generated, do not edit by hand. Unofficial, not affiliated with the developers.

Files are extracted from a local Steam install of TBH: Task Bar Hero by the
scripts in the main repo.

Layout: `<game-version>/<folder>/<Name>.png`, one git tag per game version.
Folders: heroes, skills, items, runes, pets, monsters, cube, ui, effects,
animation, i18n, misc.
Tags are immutable: pin them in URLs.

Served over CDN:
`https://cdn.jsdelivr.net/gh/victoravtr/taskbarhero-assets@<version>/<folder>/<Name>.png`

All art belongs to its respective owners. Fan use only.
